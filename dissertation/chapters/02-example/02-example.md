# Учебный пример второй главы {#sec-second}

Эта короткая глава проверяет ссылки между файлами. В общей сборке работают следующие переходы: @sec-assets, @fig-pipeline и @eq-entropy. Повторное цитирование использует ту же запись библиографии [@knuth1984].

## Работа с отдельной главой {#sec-standalone}

Главу можно собирать отдельно, когда все используемые в ней ссылки определены в выбранном файле. При отдельной сборке этой учебной главы проверка сообщит о ссылках на первую главу. Это помогает обнаружить неполный набор исходных файлов до создания документа.
