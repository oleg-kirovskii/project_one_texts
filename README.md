# project_one: тексты

Репозиторий содержит исходники диссертации, статей и общую библиографию.
Исследовательские заметки и сборочная система подключены двумя отдельными
приватными Git-подмодулями: `Generic/` и `tech/`.

## Структура

- `Generic/` — приватный подмодуль с исследовательскими материалами и инструкцией по разметке;
- `tech/` — приватный подмодуль со сборщиком и шаблонами;
- `articles/` — статьи;
- `dissertation/` — главы, иллюстрации и порядок сборки;
- `bibliography/references.bib` — общая база источников;
- `project.json` — состав диссертации, библиография и закреплённые версии инструментов.

## Клонирование

```bash
git clone --recurse-submodules <URL> project_one_texts
cd project_one_texts
```

Если репозиторий уже клонирован без подмодуля:

```bash
git submodule update --init
```

Для загрузки `Generic/` и `tech/` нужны права на оба приватных репозитория.
Восстановление внешних файлов и локальных launchers:

```bash
python tech/bootstrap.py --download --activate
```

Сборка на Ubuntu:

```bash
./build.sh dissertation --to all
```

На Windows:

```bat
build.cmd dissertation --to all
```

Подробнее: [Generic/compilation-guide.md](Generic/compilation-guide.md).

## Границы репозитория

Готовые `output/`, виртуальные окружения, скачанные компоненты, кэши и машинные
настройки в Git не включаются. Исторический каталог `archive/` также остаётся
локальным и не отслеживается. Содержимое приватных подмодулей не входит в историю этого
репозитория. До выбора файла `LICENSE` публичное чтение репозитория не означает
разрешения на переработку и распространение материалов.
